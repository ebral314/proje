# YDS / YÖKDİL Chatbot

Bu proje, YDS ve YÖKDİL gibi akademik İngilizce sınavlarına hazırlanan kullanıcılara destek sunacak bir sohbet botu geliştirmeyi amaçlar. Henüz erken aşamadadır ve kullanıcı ihtiyaçlarına göre şekillenecektir.

## Hedefler
- Kelime öğrenme ve tekrar
- Soru çözme yeteneği
- Cümle açıklaması ve düzeltme
- Akademik İngilizce yapılarının tanıtımı

## Proje Yapısı
- `src/` — Python tabanlı sohbet botu kodları
- `data/` — Soru ve kelime verilerinin yer alacağı dizin

Katkı ve geliştirme önerilerine açığız.
